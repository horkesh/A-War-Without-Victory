4. **Launch block** `if (plannedLaunchReady || elapsed > planDuration || forcedLaunch)`:

Multi-axis opening readiness (`evaluateOpeningAttackReadiness`, launch helpers): per live axis `classifyAxisOpeningAttack`; with `require_all_axes_ready` unset, result is executable only if **some axis is executable AND no non-executable axis is "approaching"** (any assigned/converging brigade `in_transit` to that axis's friendly approach OSIDs); otherwise `executable:false`. `require_all_axes_ready` is written only at op creation when true (`corps_operation_helpers.ts`, `triggered_operations.ts`); there is no deleter, and the op's final state reports it unreported ⇒ treated as absent (premise P1).
