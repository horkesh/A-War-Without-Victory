A proposal to paint this split cell RS in January 1993, April 1994, and April 1995 awaits an explicit owner decision; this publication does not apply it. The October 1995 reference also remains RBiH.

Faction colors show simulated control at each week. At measured checkpoints, amber outlines indicate mismatches, and colored circles show the current painted controller. Use settlement search or click a cell to inspect it. Zoom with the map buttons, mouse wheel, or touch pinch; drag to pan. The mismatch overlay is available only at checkpoints with historical reference data.

The standalone HTML was generated from the saved run with `tools/calibration_timeline.mjs`. Publication changes the viewer only; it does not run the simulation, change painted references, or adopt this candidate. The April 1994 strict 707/712 target and other acceptance gates remain open.
