# Writing Plans

Write an executable plan with the outcome, non-goals, exact owned surfaces, governing sources, dependencies, sequence, checks and pass criteria, authority boundaries, stopping conditions, review, and integration ownership. Use meaningful deliverables; include code only when it clarifies a non-obvious contract. A plan-only request does not authorize implementation or require an execution-choice question.

## AWWV project source

In an AWWV checkout, read `.claude/skills/writing-plans/SKILL.md` there as the maintained project workflow, plus repository `AGENTS.md`, the relevant plan/current-state authority, and relevant Codex runtime instructions. Preserve AWWV canon, cost, provenance, review, and activation boundaries.

Outside AWWV, use the generic planning contract above and save or format the plan according to the current project's conventions.
