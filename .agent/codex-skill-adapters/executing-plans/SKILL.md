# Executing Plans

Confirm the plan's scope, dependencies, authority, acceptance criteria, validation cost, and current base. Execute authorized work in dependency order through affected documentation, required checks, targeted correction, and independent review where required. Small reversible administrative steps may be handled directly. Use requested or dependency-driven checkpoints; do not stop after a fixed batch or the first failing test. Do not infer merge, publish, release, or activation authority.

## AWWV project source

In an AWWV checkout, read `.claude/skills/executing-plans/SKILL.md` there as the maintained project workflow, plus repository `AGENTS.md`, the governing plan, and relevant Codex runtime instructions. Keep Codex worktree/tool/model rules host-specific while preserving all AWWV canon and acceptance gates.

Outside AWWV, follow the generic execution contract above and the current project's integration rules.
