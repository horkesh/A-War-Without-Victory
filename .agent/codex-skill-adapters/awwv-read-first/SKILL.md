# AWWV Read First

This skill is project-specific. In an AWWV checkout, read `.claude/skills/awwv-read-first/SKILL.md` there as the maintained workflow, then read repository `AGENTS.md` and relevant Codex runtime instructions. Return the smallest task-specific map of authority, implementation, tests, and triggered boundaries.

Outside AWWV, explain that no AWWV subsystem is active and use the current project's own entrypoint if the user intended a general reading map. Do not impose AWWV canon or paths on another repository.
