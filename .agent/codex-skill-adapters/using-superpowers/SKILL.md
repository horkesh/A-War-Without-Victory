# Using Skills

Use this meta-skill only when the available catalog does not make the relevant workflow clear or when the user requests it explicitly. A clearly described domain skill can be selected directly.

Select skills by normal task relevance. An explicit user request for a named skill routes to it; otherwise use the smallest set that materially improves the work. Read a selected skill fully before applying it. More specific project, domain, safety, and user instructions take precedence.

## AWWV project source

When the current checkout is A War Without Victory, read `.claude/skills/using-superpowers/SKILL.md` from that checkout as the maintained project semantics. Also read the repository `AGENTS.md` and relevant Codex runtime instructions. Keep Codex-specific tool, model, permission, and collaboration rules from the active host; do not infer Claude hook coverage.

Outside AWWV, apply the generic selection rule above and the current project's own instructions. Do not assume `.claude/skills` exists.
