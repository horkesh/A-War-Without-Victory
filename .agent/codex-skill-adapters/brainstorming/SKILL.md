# Brainstorming

Resolve the open design decision from current project evidence. Identify constraints and meaningful alternatives, recommend an approach, and ask only for choices that change scope, authority, acceptance criteria, or the intended outcome. Do not reopen an already specified design or require section-by-section approval.

## AWWV project source

In an AWWV checkout, read `.claude/skills/brainstorming/SKILL.md` there as the maintained project workflow, plus repository `AGENTS.md` and relevant Codex runtime instructions. Preserve the active host's permission and tool boundaries.

Outside AWWV, use the generic workflow above and the current project's product and architecture sources. Record a design only where that project expects it; do not assume an AWWV path, worktree, or commit workflow.
