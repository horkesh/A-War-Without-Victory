Create or refresh a crash-safe checkpoint for the current task.

## Required output

Write a short checkpoint into the currently active report, plan, or working note that includes:

1. current objective
2. what is already done
3. files touched
4. what remains
5. next verification step
6. blockers or risks

## Rules

- Prefer updating the active working document instead of creating a new one.
- Keep it brief and scannable.
- If there is no obvious active document, use `working-on.md`.
- After writing the checkpoint, summarize it to the user in 3-6 lines.
