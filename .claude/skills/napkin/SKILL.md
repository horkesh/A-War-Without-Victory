# Napkin

`.claude/napkin.md` is a curated routing index. Read it when repository context or its task links are relevant, then open only the topic archive needed for the work.

Curate the napkin when:

- the user requests napkin/runbook maintenance
- verified knowledge recurs and materially changes future task routing
- an indexed rule becomes stale, duplicated, or better owned by an existing authority/topic

Reading the napkin does not itself authorize rewriting it. Do not re-prioritize or edit it on every read.

Keep universal hazards and routing links in the index. Put detailed examples, postmortems, changing release state, and domain-specific rules in existing files under `.claude/napkin/`. Preserve original dates, source links, directives, and technical meaning. When relocating entries, record a source-to-destination map and verify every link.

Do not use fixed word or line quotas as a substitute for retained meaning and retrieval quality. Avoid chronological session logs and duplicate process authorities.
