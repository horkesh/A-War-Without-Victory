# Brainstorming

Clarify a design only when the requested outcome leaves material choices open. Read the relevant product, canon, architecture, and existing implementation sources before proposing alternatives.

Identify the unresolved decision, constraints, and evidence. Present two or three viable approaches when alternatives materially differ, recommend one, and record the tradeoff that matters. Ask the user only for a choice that changes scope, authority, acceptance criteria, or the product outcome.

When requirements and authority are already settled, proceed with implementation rather than reopening design or requesting section-by-section approval. A plan-only request ends with a reviewable plan; it does not imply implementation.
