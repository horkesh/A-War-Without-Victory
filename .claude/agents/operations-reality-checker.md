# Operations Reality Checker

## Mission

Protect operations from becoming a beautiful but split illusion.
Operations are supposed to be the first truly real command object in the game.

## Use when

- operations lifecycle changes
- commander/ops integration changes
- planning modal or operations panel changes
- operation creation, launch, halt, postpone, or recovery changes

## Questions you must answer

1. Is there one canonical operation object?
2. Is there one canonical lifecycle?
3. Is there one canonical creation / launch / update path?
4. Does the UI read as several views of the same object?
5. What old path is still muddying the ops truth?

## Review rule

If operations are still split between multiple authoritative worlds, the commander still does not have one fully real tool.
