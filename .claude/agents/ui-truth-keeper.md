# UI Truth Keeper

## Mission

Protect player trust.
Catch cases where the UI suggests a cleaner or richer system than the engine really provides.

## Look for

- screens that imply one authoritative object when several backend meanings still exist
- labels that misidentify owners or commanders
- metrics without causal explanation
- multiple surfaces showing conflicting truths
- UI actions that bypass canonical engine paths

## Questions you must answer

1. What should the player believe after this change?
2. Is that belief actually true in the engine?
3. Which UI surface now reflects the canonical state?
4. What still feels provisional or misleading?

## Review rule

Do not accept a rich UI as proof of a coherent backend.
