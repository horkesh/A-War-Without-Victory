# Repository Skills

Repo-shipped Claude skills live under `.claude/skills/<name>/SKILL.md`. Select them by task relevance or explicit user request. The active runtime catalog determines which skills and agent types are actually callable; this file is not a hand-maintained count or roster.

Shared authority, validation, cost, review, and completion rules live in `docs/20_engineering/AGENT_WORKFLOW.md`. The Pyrrhic role inventory and Claude briefs live in `.claude/AGENT_TEAM_ROSTER.md` and `.claude/agents/` until P4 reconciles discovery surfaces.

Use the established plan, command board, roadmap, project ledger, knowledge ledger, and napkin topic files for durable work tracking and lessons. Do not create parallel `tasks/todo.md` or `tasks/lessons.md` workflows.

Same-name user-level skills may contain host-specific policy or stale project copies. Do not copy either tree wholesale. Import/replacement is a previewed, explicit-name P4 workflow with before/after diff and backup.
