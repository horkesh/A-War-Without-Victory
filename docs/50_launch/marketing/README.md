# Marketing Launch Packet

This folder contains launch-facing copy drafts. Public claims must remain traceable to implemented reports, current build evidence, or explicit future-plan markers.

Files:

- `high_concept.md` - one-page product identity, playable-now scope, pending evidence, and future/gated claims.
- `claims_inventory.md` - claim-by-claim evidence and status.
- `store_page.md` - draft store description, feature bullets, content warning, and framing note.
- `press_kit.md` - fact sheet and press materials outline.
- `screenshot_plan.md` - required screenshots, setup notes, and missing-state flags.

at 1920×1080 from the current playable build. `screenshot_plan.md` and `press_kit.md` describe
what actually shipped; `high_concept.md` and `store_page.md` remain internal drafts.

published media are tracked in `docs/40_reports/working/20260903_SHOWCASE_SCREENSHOT_GUI_AUDIT.md`.
