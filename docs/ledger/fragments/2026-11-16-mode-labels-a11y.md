## 2026-11-16 — New Game mode labels say what the choice means; the mode radios are one accessible group

**Why.** The §6 sitting of 2026-11-16 ruled that the improvising mode ships and stays the default, and that the other option is "replay the record", not "the game plays itself". "Let history run as it did" over-promised, "historical response path" was developer-speak, and the control hid its own help text from screen readers (`aria-label` equal to the title) and had no arrow-key movement. The Game Designer's review of the bright-line change made the mode help a condition before any playtest (C3), and it is only true once the bright-line change (#740) lands: the player's own consequences now follow in either mode.

**Change** (UI strings and one component, no simulation):
- `mainMenu.mode.historical`: "Replay the historical record" (BCS "Neka se ponovi historijski zapis"); `mainMenu.mode.historicalHelp`: "Other commands repeat their recorded moves where the record covers them, and act as usual elsewhere. Your own decisions stay free."; `mainMenu.mode.help`: "... Your own decisions are yours either way, and their consequences follow either way." The emergent option, including "This is the intended player campaign", is unchanged and stays first and pre-selected. Narrative and modern-wargame seats (`seat_labels.md`, variant A).
- `MainMenu.tsx` `ModeRadio`/`ModeChoice`: the accessible name is the title (`aria-labelledby`) and the description is the body (`aria-describedby`), so a screen reader hears what each choice means; the radiogroup is one tab stop (the selected radio, `tabIndex` 0/-1) and the arrow keys move the choice and the focus together (two radios wrap).
- Probe tools and tests that selected the old label follow the new one (`tools/ui/*_probe.cjs`, `paradox_local_qa.cjs`, `tests/paradox_local_qa_harness.test.ts`, `tests/ui/main_menu_opening_flow.test.ts`, plus a new test for the radiogroup behaviour).

**Evidence.** `docs/40_reports/evidence/20261116_bright_line_pr2/`: the mode screen as rendered by the dev server from this branch (default, then after Arrow Down: the historical radio selected and focused). `tsc` clean; 145 tests in the two main-menu files pass. Strings and component only: no state, no hash.

**Not done.** Rendered proof of the autonomy picker, the "Game rule" block and the Dayton and Verdict lines (the autonomy picker needs the Electron shell, which the browser dev server does not provide); the open question whether "other commands" is read as the player's own corps (change both options to "the other sides' commands" if playtest shows it); the `mainMenu.mode.emergentHelp` BCS polish.
