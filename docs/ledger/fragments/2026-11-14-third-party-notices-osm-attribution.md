## 2026-11-14 — Third-party notices and visible OpenStreetMap attribution

Pre-publication licensing. The new root `THIRD_PARTY_NOTICES.md` lists every npm package that ships: 472 name/version pairs, one per lockfile entry outside the dev tree (the root production dependencies, the tactical-map workspace dependencies that Vite bundles, and their transitive dependencies), plus Electron (the runtime) and Tailwind (its Preflight CSS ships). Each row gives the licence and the copyright line. An appendix holds each distinct licence and NOTICE text once. `node tools/licensing/generate_third_party_notices.mjs` writes the file; it is sorted, has no timestamps and uses LF, and `--check` reports a stale file. Platform-specific native binaries take their parent package's record, so the output is the same on every OS. `tests/third_party_notices.test.ts` fails when a shipped package is missing or stale, and when the file differs from a fresh generation. Positive control: deleting the real `pmtiles@3.2.1` row turned it red. The hand-written part (`tools/licensing/third_party_notices_static.md`) covers the fonts (IBM Plex and Caveat under OFL 1.1; the Open Sans map glyphs) and OpenStreetMap data under ODbL 1.0 (`osm.pmtiles`, the OSM road and waterway snapshots and the terrain scalars built from them, the geoBoundaries ADM0 outlines). It also covers Copernicus GLO-30 elevation (`terrain.pmtiles`, `hillshade.pmtiles` and the DEM clip; the two named geography reports record only "external", and the source comes from the 2026-02-28 handover and the 2026-03-20 terrain report), geoBoundaries (CC BY 4.0), the ETOPO 2022 and Natural Earth sources of the opening texture, and the VSCO 2 CE samples (CC0, `docs/audio/LICENSES/`).

The war map and the minimap now carry a 12px "© OpenStreetMap contributors" plate in the dark NATO ops style (near-black, green hairline, gold text), linking to openstreetmap.org/copyright. A rendered check on the browser dev map (tracked RS save; 1920×1080 EN, 1366×768 BCS) placed the war-map plate bottom-left on the legend column, clear of the Find button. The default Inbox rail hides the whole minimap plate; when a left rail replaces the Inbox, the minimap plate shows and the war-map plate is covered. The Credits screen gains a Map Data section with the ODbL line (BCS "© OpenStreetMap saradnici"). The same check found that Credits, opened from the main menu, rendered behind it (MODAL_HARD 8500 under HARD_MODAL 9000) and that its backdrop button covered the panel. Credits now uses HARD_MODAL like Settings, and its panel is positioned above the backdrop.

External links in the desktop app. Before this change, `electron-main.cjs` had no window-open or navigation guard. A `target="_blank"` link, such as the existing Dayton boundary-map OSM credit, opened the site in a new app window under Electron's default handling. Now `installExternalLinkPolicy` runs on every new webContents (`app.on('web-contents-created')`; DevTools is skipped). It denies every popup and sends an https link on the `EXTERNAL_LINK_HOSTS` allow-list (`openstreetmap.org`, `www.openstreetmap.org`) to `shell.openExternal`, so the player's browser opens it. `will-navigate` and `will-frame-navigate` cancel any navigation that leaves app content (`awwv://`, the loopback map or dev server, `about:` and `blob:`). The policy is a marked block inside `electron-main.cjs`, because a new `src/desktop` module would need an electron-builder `files` change, and packaging is paused. `tests/desktop_external_link_policy.test.ts` evaluates the block against a fake webContents. It checks the URL rules, the popup and navigation handlers and the wiring, and fails when a renderer `<a href>` points at a host that is not allow-listed. Positive controls on the real file: removing the wiring, allowing popups, or dropping `www.openstreetmap.org` from the list each turned it red (1, 1 and 5 failures). The plates and the Credits link therefore link in the desktop app too. The rule is written down in `DESKTOP_GUI_IPC_CONTRACT.md` ("External links and navigation"). It is unit-tested only: no packaged Electron click-through has been run.

Tool-only dependencies moved out of the shipped set (owner request). electron-builder copies every production dependency into the app, and 24 root `dependencies` were used only by tools. A measurement of the shipped code found:
- `desktop_sim.cjs` (esbuild, metafile) bundles one npm package, `@anthropic-ai/sdk`.
- The tactical-map Vite build bundles 32: deck.gl and its luma/loaders/math/probe parts, maplibre-gl, pmtiles, React, zustand and leaves.
- The warroom build bundles only React.
- The packaged main-process files require only Node built-ins and `electron`.

`@modelcontextprotocol/sdk`, `@napi-rs/canvas`, the five `@turf/*` packages, the `@types/topojson-*` packages, `adm-zip`, `concaveman`, `geotiff`, `jsts`, `martinez-polygon-clipping`, `pdfjs-dist`, `pngjs`, `polyclip-ts`, `svg-path-parser`, `three`, `topojson-client`/`-server`/`-simplify` and `xlsx` became root devDependencies. The map workspace's unused `deck.gl` metapackage (which pulled in `@deck.gl/carto` with CC-BY `cartocolor`, plus arcgis, google-maps and more) and its unused `@turf/*` 6.5.0 became workspace devDependencies. Nothing was deleted, and versions are unchanged. `package-lock.json` changes only dependency-type flags (507 entries gain `"dev": true`, 4 lose `devOptional`), plus the two manifest entries and #612's `license` field. npm's regeneration also dropped 30 electron-builder optional-peer entries; those were restored from the previous lock, so `npm ci --legacy-peer-deps` installs the same tree (exit 0, same 765 top-level entries).

The shipped set is now 81 packages instead of 472, and the notices file is 88 KB instead of 416 KB. Production lock paths fall from 574 to 82, roughly 400 MB to 80 MB of `node_modules`. All 33 packages measured in the bundles stay in the set. `tests/third_party_notices.test.ts` adds two checks:
- a regression lock that keeps the moved tools out of the shipped set;
- a guard that fails when shipped `src/` (excluding `src/cli` and build configs) imports a package outside the shipped set, so bundled code always has a notice. Positive control: an `xlsx` import added to `src/ui/map/main.tsx` turned it red.

This changes what the packager copies. The CI desktop package and packaged-runtime-probe gates, which a lockfile change triggers, are the runtime proof. Electron itself could not run here.

No sim or data change. The packaging configuration (electron-builder `build` block) is unchanged. Still open: packaged builds do not yet include the notices file, because packaging is paused. Not recorded and needing owner confirmation: the Copernicus attribution wording, the Open Sans glyphs' upstream, the origin of `bih_adm3_1990.geojson`, and the licence of `@mapbox/jsonlint-lines-primitives` (none declared).
