## 2026-11-14 — Owner playtest UI round 2: enemy-contact chip and legend, collapsed list off the player screens

UI only; no sim, state or calibration change. Two findings from the R8 dry run and the playtest register (the Verdict headline and the Dayton nav clip moved to the Council fix 1 lane).

1. **PK3, enemy-contact chip and legend.** The unidentified enemy counter printed "EN", the generic two-letter fallback of `drawTacticalSymbol` (`enemy_contact` fell through to `kind.slice(0, 2)`). It now prints a "?" (new `enemy_contact` case in `formationIcons.ts`). The political-mode map legend gains four rows under the counter key: the "?" chip (EN "Spotted enemy unit, unidentified", BCS "Uočena neprijateljska jedinica, neidentificirana"), scouted ground (side tint), fogged ground (the dark-brown fog wash from `MAP_PAPER_PALETTE.fog`), and the dashed enclave outline. Swatches use the same palette constants as the map layers; BCS strings added for all four.
2. **F1e, collapsed-municipality list.** The cumulative "permanently collapsed municipalities" figure is gone from SituationTab, the War Summary sustainment line, the sitrep headline and alert (`operational_sitrep_views.ts`; the critical-sustainability line now shows when it applies, instead of being hidden behind the collapsed alert) and the ticker (`sustainability_collapse` is no longer a ticker line). The data field `sustainment.collapsedMunicipalities` is kept for the legacy warroom panels. The three unused i18n keys are removed. Separately, `turn_event_generator.detectSustainabilityCollapses` looked up `political_controllers[munId]`; that map is keyed by OSID, so the lookup was always empty and every collapse event was attributed to the player. It now takes the majority holder of the municipality's OSIDs (`deriveMunicipalityControllerByOsid`, now exported from `war_data_extractor.ts`, the same function the sitrep supply count uses). The sibling lookup in `warroom_state.ts` (displacement-out totals) has the same shape and is registered, not changed here.

Tests: `enemy_contact_chip_symbol`, `map_mode_counter_legend` (new rows, EN and BCS), `turn_event_collapse_attribution` (holder attribution, no ticker line); `operational_sitrep_views`, `r7_english_readability_phase1` and `war_summary_campaign_cost_i18n` updated for the removed list. Rendered before/after screenshots are in `docs/40_reports/evidence/20261114_ui_round2/`.
