New Lessons Added This Period

[Architecture] Corps formation must exist in formations map

A corps_id on a brigade means nothing if the corps doesn't exist as a formation. hvo_central_bosnia was referenced but never created in war-start scenarios. Sector system returned 0 sectors.

[Architecture] Readiness state machines need irreversible transitions

Once a brigade passes forming, it should never revert. Low cohesion after activation = overextended, not forming. 29 HRHB brigades oscillated every turn.

[Sectors] Brigade-presence protects at component level

If ANY edge in a connected component has a minority corps brigade, ALL edges of that corps must be protected from consolidation. Per-edge protection drains enclave corps edge-by-edge.

[Pipeline] Late-issued orders survive to next turn

Orders issued at step 708 persist to next turn's step 496. Column march orders from advance-sector-offensives are consumed by osid-column-movement because 496 < 517.

[MapLibre] isStyleLoaded() false during map.on('load')

Adding sources inside the load callback puts the style back into non-loaded state. Never guard init source/layer creation on isStyleLoaded().

[MapLibre] visibility:hidden > display:none for map toggles

Toggling display:none on MapLibre containers causes context loss. Use CSS visibility/opacity and call map.resize() inside requestAnimationFrame.
