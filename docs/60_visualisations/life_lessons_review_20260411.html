New Lesson 1 — Architecture

Validator exemptions that suppress real sim failures are always wrong — fix the sim

Source: bb454db4 → dc742d9e sequence. The validator correctly identified a sim gap. Exempting the brigade hid the signal.

Pattern: When a validator fails, the validator is probably right. Fix the system under test, not the test harness. A passing validator via exemption is epistemic debt — it makes the next failure invisible.

Add to: docs/life_lessons/architecture.md

New Lesson 2 — Architecture

Latent contract violations are worth closing proactively

Source: 18546201 (reserve cap guard). Zero delta — n1420 and n1421 are byte-identical. The code path could create 2-reserve sectors but never did in practice.

Pattern: If a code path CAN violate an invariant, fix it now. Latent violations become live violations under conditions you haven't tested. The cost of a 5-line guard is always less than the cost of debugging a future invariant breach with no reproduction case.
