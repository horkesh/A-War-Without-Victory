8 — Calibration Plan
Single Priority
Fix engine bugs (P0: brigade_history, posture lifecycle) FIRST, then address military casualty rates (P1) before attempting any territory calibration. Territory tuning without fixing the underlying combat model will produce false calibration.
Priority 0 — Engine Bugs
P0
Fix brigade_history recording
recordAttackerEngagements() / recordDefenderEngagement() results not persisting. Check if FIFO writes to correct FormationState field, or if serialization strips it. 0/207 formations have any entries despite 103 battles.
P0
Fix posture lifecycle
Postures reset to 'defend' after combat within the same turn. An attacking brigade should show 'attack' posture until it receives a different order. Only 3 of 8 postures observable in state.
P0
Fix displaced_out accumulator
displacement_state.displaced_out always 0 despite 27,909 displacement events firing. Summary counter not aggregating from event log.
Priority 1 — Casualty & Combat Tuning
P1
Reduce background attrition rates
Military KIA running 2–3× pace. Check frontline_attrition.ts and pool_population.ts. The 25% pool exhaustion rate may need reduction to 15–20%. Check bombardment exposure attrition.
P1
Fix Serb civilian casualty model
RS civilian deaths 10,860 at w40 (full-war total ~4k). Displacement/ethnic-cleansing mechanic needs faction-context: civilians of the controlling faction in their own territory should not be killed at minority rates.
P1
Rebalance attacker/defender casualty ratio
Current 4.78:1 is too skewed (target 2.5–3:1). Consider increasing BASE_DEFENDER_CASUALTY_RATE or reducing BASE_ATTACKER_CASUALTY_RATE.
Priority 2 — Territory & Combat Tempo
P2
Address VRS post-w20 tempo collapse
Transition from general_offensive to balanced is too sharp. Tune 'balanced' stance to allow more offensive ops. RS_EARLY_WAR_END_WEEK=20 is load-bearing — do not change. Increase aggression_modifier so balanced corps still attack high-value targets.
P2
Address late-game entrenchment wall
At 11.9 avg entrenchment turns, defenders are very hard to dislodge. Consider: artillery suppression, concentration bonus for multi-brigade assaults, diminishing returns past ~6 turns.
P2
Enable counterattacks for RBiH/HRHB
Zero attack orders from non-RS factions is unrealistic. Even general_defensive should allow local counterattacks when opportunity presents (recently captured territory, weak enemy detected).
Priority 3 — Supply, Exhaustion & Depth
P3
Fix HRHB supply isolation
Mainland Herzegovina HRHB should receive adequate patron aid through Croatia. Only isolated pockets should drain. General supply at 6.9/100 is near-starvation.
P3
RS/RBiH supply drain
Both at 100% after 40 weeks is unrealistic. Ongoing operations should consume supplies. Supply system may only fire for isolated pockets.
P3
Make combat fatigue meaningful
With current parameters (1.3 battles/bde/40w, +2 fatigue/battle, -1/turn recovery), fatigue never accumulates. Increase fatigue gain, reduce recovery, or add non-combat fatigue sources.
P3
VRS stance regression
All VRS corps defensive by w40. Historical: VRS maintained offensive capability into 1993 (Cerska, Srebrenica). Maintain 2–3 corps at balanced/offensive through w52.
