Explicitly Rejected Won't Build

LOS / Visibility Cones

Ray-casting against DEM in the browser is expensive and hard to read at strategic scale. This is a tactical feature on a strategic game.

Full 3D Terrain on Main Map

Tried it. At strategic zoom, 3D extrusion makes polygon fills unreadable and front lines distort. Ops modal (focused AO) is the right place for 3D.

3D Battle Replay Animation

Sim resolves battles as single-turn discrete events, not multi-step engagements. No "attack sequence" to animate. A flyover with a static battle card is more honest.

Deck.gl HeatmapLayer for Threat Density

Defense map mode already exists. Another heat layer adds complexity without new information. Better to fix the existing Defense mode.

Pulsing Animated ScatterplotLayer Markers

Looks flashy but adds no information. Battle markers already pulse via MapLibre. More animation does not equal more understanding.

Technical Constraints (Realism Check)

What Works

  • Interleaved mode: Deck.gl layers in MapLibre stack via beforeId. Active, proven.
  • PathStyleExtension dashes: rAF loop, minimal CPU. Proven in ops modal.
  • Deck.gl picking: Per-pixel onHover/onClick. Better than queryRenderedFeatures for overlaps.
  • queryTerrainElevation: Returns meters at any LngLat. Works in ops modal.
  • Performance budget: Under 20 Deck layers for 60fps. Currently 5 in ops modal.

What Doesn't

  • 3D terrain on main map: Distorts polygon fills at strategic zoom. Keep flat.
  • Browser DEM sampling: 20MB TIFF load + parsing. Pre-compute per-OSID instead.
  • _TerrainExtension: Experimental. Uses Deck.gl's own terrain, not MapLibre's setTerrain. Not interoperable.
  • Deck.gl layers on MapLibre terrain: Don't auto-drape. Only MapLibre's own layers drape natively.
!

Design Principle

The foundation is already built: 3D terrain, Deck.gl overlay, combat effectiveness, terrain scalars, Icon.tsx. What's missing is not capability — it's connection. Battle data exists but markers don't link to it. Icons exist but panels don't use them. Terrain data exists but the map doesn't show it. The highest-impact work is wiring existing systems together, not building new ones.
