Alphabetical tiebreak = architectural cascade risk
Sub_segment first-pass assignment uses alphabetical tiebreak when all brigades have equal tiny scores for a distant sub_segment. This is not a bug — it's a deterministic fallback. But it means any change to scoring (penalties, bonuses) that shifts one brigade's assignment can cascade unpredictably to ALL other brigades in the sector. Test cross-sector effects before committing any sub_segment scoring change.
