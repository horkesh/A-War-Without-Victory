Architecture Organic emergence beats hard caps 2026-03-06
VRS tempo needed to decay over a 40-week war. Designers expected explicit phase transitions to produce this; instead tempo locked at max aggression and never slowed.
Wrong Approach
Phase switches ("RS goes defensive at week X"), hardcoded personnel caps, forced stance transitions. Creates artificial cliffs that don't match historical gradual degradation.
Right Approach
Fatigue (+2/battle, recovery only off frontline), supply drain (0.045/formation), entrenchment walls (sqrt curve), pool demographics. RS attacks naturally decline 8→1 by w40.
Do Instead
Find the emergent lever (fatigue, supply, pool exhaustion). If you can't, the underlying system is missing a mechanic. Never add a hard cap or phase switch.
Calibration Fixing one faction cascades to all others 2026-03-08
HRHB was taking 6.3k KIA from phantom attrition on cold (Graz Accords) fronts. After fixing it, HRHB was suddenly too healthy — changing territorial dynamics and RBiH mobilization pressure.
Wrong Approach
Fixing HRHB attrition in isolation, expecting other factions to stay stable.
Right Approach
Treat faction calibration as a system. HRHB fix required pool scale 1.60→1.05 AND RBiH scale 0.18→0.25 to maintain equilibrium.
Do Instead
After fixing any faction-specific bug, immediately check all three factions' troop strength, KIA, and territorial outcomes. Budget time for cascade recalibration.
Debugging The bug is never where you think it is 2026-03-08

Wrong Approach

Right Approach

Do Instead

Debugging Formation state is a state machine — guard transitions, not values 2026-03-08
Number.isInteger(1.5) === false caused the fatigue recovery guard to skip recovery, leaving fractional fatigue unreset every turn. Looked like a formula error.
Wrong Approach
Checking if a value is an integer as a guard for a state transition. This is a type assumption, not a state guard.
Right Approach
Guard with typeof !== 'number' (data presence), not Number.isInteger (value shape). Guard the transition, not the value format.
Do Instead
For any state machine field, document transitions explicitly. Never guard with shape assumptions (isInteger, isArray) when presence is the right gate.
Architecture Port systems incrementally, not all-at-once 2026-03-08

Wrong Approach
Remove the entire legacy system at once. Breaks 4+ consumers simultaneously — untestable, uncommittable.
Right Approach
Port one consumer at a time (frontline_attrition.ts only). Each port = clean, testable, committable unit.
Do Instead
Enumerate ALL consumers of the old system first. Port one at a time, verify calibration between each, delete old system only when the last consumer is ported.

Operations entered execution phase and stayed there indefinitely with no attacks, triggering execution_without_attack_orders warnings.

Process Determinism requires explicit sorting, not hope 2026-03-04
Object.keys() and Object.entries() iteration order is not guaranteed. Map source updates diverged across runs on different machines.
Wrong Approach
Assuming iteration order is stable because it "usually is." Single-machine testing that happens to be consistent.
Right Approach
Every iteration over maps, every Object.keys(), every derived array must be explicitly sorted via strictCompare. Document the sorting contract in function signatures.
Do Instead
Search for any Object.keys() or Object.entries() without .sort(strictCompare). Each one is a latent nondeterminism bug.

GUI Defer heavy work off the main thread 2026-03-01
Formation icon creation (canvas draw + getImageData + MapLibre GPU upload) was synchronous in a single rAF, freezing the UI for hundreds of milliseconds per load.
Wrong Approach
DOM manipulation, image encoding, and GPU operations synchronously in the render path.
Right Approach
requestIdleCallback with 400ms timeout deferred icon loading without blocking UI. Heavy work belongs off the hot path.
Do Instead
Any work touching DOM, canvas, or GPU inside a render callback needs a requestIdleCallback or next-tick defer. If the UI stutters during load, the render path has synchronous work.
