## Context

**This milestone is DAY SHIFT / USER-DRIVEN.** Night shift cannot write store descriptions, take screenshots, or set up Discord servers.

## Deliverables

### Phase 1: Steam Store Page (~1 session)
**Assigned to:** Product Manager + User

- [ ] **Task 1.1:** Store page description
  - Write: short description (300 characters): "A negative-sum wargame about the Bosnian War. Nobody wins. The question is: how much do you lose?"
  - Write: long description (1000-2000 words): game philosophy, features list, faction overview, historical grounding, AI features, educational value
  - Tone: somber, respectful, honest about the subject matter. NOT "fun-to-play action." This is a serious simulation.
  - Tags: Strategy, Wargame, Grand Strategy, Historical, Military, Singleplayer, Atmospheric, Story Rich

- [ ] **Task 1.2:** Screenshots (5-10)
  - Capture from production build at 1920×1080:
    1. Political map overview (full war, faction territories visible)
    2. Tactical map with formation icons and front lines
    3. Operations planning modal with Bezier arrows
    4. Command briefing after a dramatic turn
    5. Dayton negotiation screen
    6. Verdict/Pyrrhic Score screen
    7. Warroom (faction HQ)
    8. Event modal (historical event with decision)
    9. Codex entry (educational content)
    10. Tutorial overlay (onboarding)
  - Format: PNG, 1920×1080

- [ ] **Task 1.3:** Trailer (60-90 seconds)
  - Content: gameplay footage intercut with title cards
  - Opening: "April 6, 1992. Sarajevo." Black screen with date.
  - Middle: rapid montage — map mode switches, battles, events, operations, fronts shifting
  - Text cards: "Three factions. Four years. One table." "A War Without Victory."
  - Ending: Pyrrhic Score screen → Pyrrhic Games logo
  - Music: somber score (v0.5.3 war_ambient or verdict theme)
  - No voiceover. Let the game speak.
  - **This may require video editing software (external to code)**

- [ ] **Task 1.4:** System requirements
  - Minimum: Intel i3, 8GB RAM, integrated graphics, 1GB storage
  - Recommended: Intel i5, 16GB RAM, dedicated GPU, 2GB storage
  - Based on: v0.7.0 + v0.9.0 performance benchmarks

**Assigned to:** Product Manager

- [ ] **Task 2.1:** Create press kit
  - Create: `docs/marketing/press_kit/` directory
  - Contents:

    - Logo files (PNG + SVG, light + dark backgrounds)
    - Key art (if available from visual asset pipeline)

- [ ] **Task 2.2:** Review copy distribution
  - Identify: 10-20 strategy game reviewers, YouTubers, podcasters
  - Prepare: Steam keys or direct download links
  - Write: brief personalized pitch per reviewer
