### Phase 2: Edge Case Hardening (~1 session)
**Assigned to:** QA Engineer

- [ ] **Task 2.1:** Long game stress test
  - Run: 300-turn game (beyond historical 208 weeks — what happens if player refuses Dayton?)
  - Verify: no crashes, no integer overflows, no unbounded growth
  - Game should force-end at a reasonable point or degrade gracefully

- [ ] **Task 2.2:** Unusual faction combinations
  - Test: play as HRHB and immediately break alliance with RBiH (turn 1)
  - Test: play as RS and accept every peace plan
  - Test: play as RBiH and launch no operations (pure defense)
  - Verify: no crashes, no game-breaking state, reasonable outcomes

- [ ] **Task 2.3:** Alliance-break timing edge cases
  - Test: break RBiH-HRHB alliance at every possible turn (w1, w10, w40, w100)
  - Verify: Graz Accords, Washington Agreement, corps realignment all handle correctly
  - Verify: no orphaned brigades, no phantom fronts

- [ ] **Task 2.4:** Save compatibility
  - Save at turns 1, 50, 100, 150, 188 during each edge case test
  - Load each save, advance 10 turns
  - Verify: no state corruption

**Gate:** No crashes in any edge case. Game handles unusual player behavior gracefully.

### Phase 3: Determinism Verification (~0.5 session)
**Assigned to:** Systems Programmer

- [ ] **Task 3.1:** Cross-platform determinism
  - Run: same scenario on Windows + Mac (or Linux via WSL)
  - Compare: `run_summary.json` hash
  - Verify: identical hash = identical output = deterministic
  - If different: investigate floating-point differences, sort stability, file system ordering

- [ ] **Task 3.2:** Replay determinism
  - Run: scenario twice with identical inputs (no AI, same seed)
  - Compare: weekly_report.jsonl line-by-line
  - Verify: identical output = replay-safe
  - Test: with AI enabled (Commander mode) — decisions are logged, but AI responses are non-deterministic so game state diverges (this is expected and documented)

- [ ] **Task 3.3:** Document determinism guarantees
  - Create: `docs/20_engineering/DETERMINISM_GUARANTEES.md`
  - States: "Without AI features, identical inputs produce identical outputs across platforms"
  - States: "AI features (Commander/Observer mode) introduce non-determinism in narrative content (AARs, analysis) but not in game-mechanical outcomes (which use formula bot fallback)"
  - Lists: all sources of determinism (deterministicRandom, strictCompare, sorted iteration)

**Gate:** Determinism verified across platforms. Guarantees documented.
