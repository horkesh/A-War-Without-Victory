# v0.9.0 — Final QA Sweep — Implementation Plan

**Date:** 2026-03-16
**Status:** PLAN — ready for execution
**Overseer:** Orchestrator + QA Engineer
**Prerequisites:** v0.8.2 (Platform Packaging) complete. All platforms build. Game is feature-frozen and balanced.

---

## Context

This is the last quality gate before gold. The goal is **zero known crash bugs** and **zero known save-breaking bugs.** Cosmetic issues and minor UX niggles are documented but not blocking.

---

## Deliverables

### Phase 1: Full Regression Test (~1-2 sessions)
**Assigned to:** QA Engineer

- [ ] **Task 1.1:** Automated test suite
  - Run: `npm run test:vitest` — all 900+ tests must pass
  - Run: `npx tsc --noEmit` — zero errors
  - Run: `npm run calibrate:full` — all benchmarks pass
  - Run: determinism check — same hash as v0.8.1 baseline

- [ ] **Task 1.2:** Scenario matrix test
  - For each scenario (tutorial, Apr 1992, Sep 1991, Jan 1993):
    - For each faction (RBiH, RS, HRHB):
      - Play 5 turns → save → load → play 5 more → verify state correct
      - Advance to Dayton (auto-play if available) → verify verdict screen shows
      - Total: 4 scenarios × 3 factions = 12 playthroughs (abbreviated)

- [ ] **Task 1.3:** Feature exercise checklist
  - [ ] Tutorial: complete all 11 objectives
  - [ ] Events: at least 10 events fire in 20 turns (including 1 decision event)
  - [ ] Operations: launch and complete 1 operation
  - [ ] Peace plan: respond to at least 1 peace plan
  - [ ] Dayton: complete negotiation and see verdict
  - [ ] Achievements: unlock at least 3 achievements
  - [ ] Codex: open and search codex
  - [ ] Essays: unlock and read at least 1 essay
  - [ ] AI advisor: ask 1 question (if API key set, otherwise verify Cadet mode)
  - [ ] Settings: change 1 setting, verify persistence
  - [ ] Save/Load: save, quit, relaunch, load
  - [ ] Audio: verify SFX on click, music on turn advance (if audio assets present)
  - [ ] Map modes: cycle through all 7 modes, verify legends
  - [ ] Keyboard: play 3 turns using only keyboard
  - [ ] Colorblind: switch to each mode, verify map readability
  - [ ] Localization: switch to BCS, verify UI updates

- [ ] **Task 1.4:** Save compatibility
  - Load: saves from v0.7.x, v0.8.0, v0.8.1
  - Verify: old saves load with default values for new fields
  - Verify: no crashes from missing fields

**Gate:** All automated tests pass. Feature checklist 100% complete. No crashes.

### Phase 2: Bug Triage & Fix (~1 session)
**Assigned to:** Per-bug assignment

- [ ] **Task 2.1:** Triage all found issues
  - Classify: P0 (crash/save-break), P1 (major UX), P2 (cosmetic), P3 (won't fix for 1.0)
  - P0: fix immediately
  - P1: fix if time allows (time-boxed to 1 session)
  - P2/P3: document in known issues, fix post-1.0

- [ ] **Task 2.2:** Fix all P0 issues
  - Each fix: one commit, regression test after
  - Re-run affected scenario from Phase 1

- [ ] **Task 2.3:** Document known issues
  - Create: `docs/KNOWN_ISSUES_v1.0.md`
  - List: all P2/P3 issues with workarounds where applicable
  - Honest: players appreciate transparency about known limitations

**Gate:** Zero P0 issues. Known issues documented.

> /simplify → commit per fix

---

### Phase 3: Performance Verification (~0.5 session)
**Assigned to:** Performance Engineer

- [ ] **Task 3.1:** Re-run performance benchmarks from v0.7.0
  - Compare: against v0.7.0 baseline
  - Verify: no significant regression from v0.7.1-v0.8.x changes
  - If regression >20%: investigate and fix

- [ ] **Task 3.2:** Production build performance
  - Test: performance on PRODUCTION build (not dev build)
  - Production builds may be faster (minified, tree-shaken) or slower (no source maps for debugging)
  - Verify: <100ms turn time, 60fps map, <3s startup

- [ ] **Task 3.3:** Document final performance numbers
  - Update: `docs/40_reports/PERFORMANCE_BENCHMARKS.md`
  - Record: final numbers on reference hardware
  - Include: in press kit / store page technical specs

**Gate:** Performance meets v0.7.0 targets. Final numbers documented.
