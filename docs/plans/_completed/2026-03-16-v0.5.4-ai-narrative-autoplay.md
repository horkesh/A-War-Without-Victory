## Context

v0.4.5 built the AI infrastructure: Anthropic SDK integration, prompt builder, response parser, personality profiles for all commanders, decision logging, and multi-tier routing (Cadet/Observer/Commander). The player advisor is live.

v0.5.4 extends this into **narrative** — making the AI produce human-readable content that enriches the game experience. Corps commanders write field reports. The game generates a post-war analysis. And the crown jewel: AI-vs-AI auto-play where Claude commands all three factions.

**Cost model** (from CLAUDE_AI_COMMANDER_DESIGN.md):
- After-Action Reports: Haiku, ~$0.005/battle, ~50-100 battles/game = $0.25-0.50/game
- Post-game analysis: Sonnet, ~$0.10/game
- Auto-play (all 3 factions): ~$5-15/game depending on model tier
- Contextual advisor: Haiku, ~$0.01/query

All features require API key. Cadet Mode (no API) always works — these features simply don't appear.

## Architectural Decisions (FLAGGED FOR USER REVIEW)

1. **AARs are cosmetic-only**: Battle reports from AI never affect game state, morale, or scoring. They're purely narrative flavor. This avoids any determinism concerns — different API responses don't change the game.

2. **Auto-play model cost**: A full 188-turn auto-play game with Commander tier (Sonnet for army, Haiku for corps) costs ~$5-15. This is acceptable for a calibration/entertainment feature that runs rarely. Recruit tier (all Haiku) reduces to ~$2-5.

3. **Decision log for replay**: All AI decisions are logged. A replay system could theoretically re-apply logged decisions without API calls, enabling deterministic replay of AI games. This is NOT implemented in this plan but the data structure supports it.

4. **No AI-generated audio**: AARs and analysis are text-only. AI voice synthesis for commander reports is deferred indefinitely (quality, cost, and tone concerns).
