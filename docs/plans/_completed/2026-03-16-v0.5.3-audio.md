## Context

The game currently has zero audio. For a wargame about the Bosnian War, audio must be somber, restrained, and historically respectful — not bombastic. Think: ambient documentary score, radio static, typewriter clicks, distant artillery. The aesthetic is a NATO ops center receiving field reports, not a Hollywood action movie.

**Audio library choice:** Howler.js (MIT, battle-tested, works in Electron/browser, supports sprites, fading, spatial). Already commonly used in Electron apps. Alternative: Web Audio API directly (more control, more boilerplate). **Pre-decision: Howler.js** unless architect objects.

**Asset strategy:** Audio assets are NOT generated by AI. They must be sourced from:
- Royalty-free libraries (freesound.org, OpenGameArt, etc.)
- Original composition (if budget allows)
- Placeholder silence/beeps until real assets delivered

The plan implements the **audio engine and integration points**. Asset sourcing is a parallel workstream.

## Asset Sourcing Strategy (PARALLEL WORKSTREAM — NOT BLOCKING)

Audio assets are sourced separately from implementation:
1. **Placeholder phase** (this plan): beeps and tones that prove the engine works
2. **Asset integration** (post-plan): real audio files drop into `audio/assets/`, engine picks them up automatically via manifest
3. **Sources**: freesound.org (CC0/CC-BY), royalty-free game audio packs, or original composition
4. **Requirements per asset**:
   - SFX: mono, 44.1kHz, WAV or OGG, <500KB each
   - Music: stereo, 44.1kHz, OGG, 1-3 minute loops, <5MB each
   - Total budget: ~30MB for all audio

## Architectural Decisions (FLAGGED FOR USER REVIEW)

1. **Howler.js over Web Audio API**: Simpler API, handles cross-browser issues, sprite support. Trade-off: 30KB dependency. Acceptable for a desktop Electron app.

2. **Music is non-diegetic only**: No in-world radio, no ambient war sounds spatialized to map position. Those would require significant engineering (spatial audio tied to map viewport). Deferred indefinitely.

3. **No audio during headless sim runs**: AudioEngine is UI-only (`src/ui/map/`). Scenario runner and tests never touch audio. No determinism concerns.
