## Context

## Architectural Decisions (FLAGGED FOR USER REVIEW)

1. **No charting library**: Territory timeline uses raw SVG (not Chart.js/D3). Keeps bundle small. Trade-off: less polished but adequate for 3 area bands.

2. **Achievements are deterministic**: Pure functions of game state. Same playthrough = same achievements. No "you were online on achievement unlock day" nonsense.

3. **Save metadata is a wrapper, not inlined**: `{ meta: {}, state: {} }` structure. Old saves without wrapper still load (backward compatible). Metadata computed at save time, not stored in GameState.

4. **Playtime is wall-clock, not sim-time**: Counts seconds while game is active (not auto-play speed). Paused time excluded.
