## Architectural Decisions (FLAGGED FOR USER REVIEW)

1. **Briefing storage**: Plan stores `last_briefing` in GameState (deterministic, save-compatible). Alternative: compute on-the-fly in UI. Spec chose GameState. Adds ~2-5KB per save.

2. **Menu routing**: Plan uses React state machine in App.tsx (MainMenu → Game → Pause). Alternative: React Router. State machine is simpler for a single-window Electron app.

3. **Settings file format**: JSON in Electron userData directory. No encryption. Player-editable (modding friendly).
