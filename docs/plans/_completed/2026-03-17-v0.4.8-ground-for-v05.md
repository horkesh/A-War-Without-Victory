**Step 2: Implement `computeReturnMarches()`**

Logic:
1. On operation recovery completion, scan `participating_brigades` + `loaned_brigades`
2. For each: extract `home_osid` municipality vs current `location_osid` municipality
3. If different municipality AND brigade not in another active operation AND not disrupted:
   - BFS from current location through friendly territory toward any OSID in home municipality
   - Issue column march order (reuse `brigade_movement_orders` pattern)
4. Cap march distance at 6 hops (same as MAX_OP_LOAN_DISTANCE)
5. Deterministic: sorted by brigade_id

**Step 3: Wire into sector_offensive.ts recovery path**

In `advanceSectorOffensives()`, when operation transitions from recovery to completion:
```typescript
const returnMarches = computeReturnMarches(op, state, adjacency, friendlyOsids);
for (const march of returnMarches) {
    issueBrigadeMovementOrder(state, march.brigade_id, march.target_osid);
}
```
