## Architectural Decisions (FLAGGED FOR USER REVIEW)

1. **Steam is optional.** The game works standalone without Steam. Steam adds achievements + cloud saves + distribution. If Steamworks approval is delayed, launch standalone first.

2. **No DRM.** The game is DRM-free whether on Steam or standalone. This aligns with the niche wargame market expectation and Pyrrhic Games values.

3. **Auto-update via GitHub Releases** (not Steam). Standalone players get updates too. Steam players get updates via Steam's system.

4. **Apple Developer account ($99/year) required for Mac.** Without it, macOS build is blocked by Gatekeeper. User must decide if Mac is a launch priority.
