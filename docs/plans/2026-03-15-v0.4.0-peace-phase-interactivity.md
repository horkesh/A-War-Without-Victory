## Deliverables

### 1. End-to-End Investment Flow Verification (~0.5 session)

The investment flow technically works but hasn't been verified as a player experience. Tasks:

- [ ] **Launch Sep 1991 scenario** in desktop app, select a faction
- [ ] **Verify advance-turn dialog** shows "Open Investment Map" during peace phase
- [ ] **Verify Phase0PreparationMap** renders municipalities with correct control colors
- [ ] **Verify InvestmentPanel** renders on municipality click with correct costs, types, coordination
- [ ] **Verify staging** — invest, see staged count, undo, re-invest
- [ ] **Verify turn advance** — directives applied, capital deducted, org-pen changes visible
- [ ] **Fix any wiring issues** found during verification
- [ ] **Document** the peace phase player flow in a test protocol

### 2. Peace→War Transition Screen (~1 session)

When the referendum fires and `war_start_turn` arrives, the game transitions from peace to war. This moment needs a dramatic screen.

**New component:** `PeaceWarTransition.tsx`

Following the canonical visual style (glassmorphism, accent-gold, floating panel):

- [ ] **Trigger:** Renders when `state.meta.phase` changes from `peace` to `war` (detect via state comparison in App.tsx or store)
- [ ] **Content:**
  - Header: "WAR BEGINS" + date (e.g., "6 April 1992")
  - Faction briefing: 2-3 sentences of narrative per faction
  - OOB summary: brigade count, personnel, equipment per faction (from formations)
  - Front overview: territory %, number of front edges, key contested areas
  - "The referendum has been held. The international community has recognized Bosnia and Herzegovina. The JNA withdraws — but leaves everything behind."
- [ ] **Interaction:** Single "Begin" button dismisses the modal and reveals the war-phase UI
- [ ] **State:** Store `transitionSeen: boolean` in gameStore so it only shows once per game

### 3. Tactical Map Peace Overlays (~0.5 session)

The tactical map during peace phase should show meaningful data beyond basic political control.

- [ ] **Org-pen heat map mode** — new map mode (or sub-mode of Political) showing organizational penetration intensity per municipality. Color gradient: low penetration (dim) → high penetration (bright faction color). Data source: `state.political.municipalities[munId].organizational_penetration`
- [ ] **Municipality click during peace** — settlement panel shows stability score, org-pen breakdown (police, TO, party, paramilitary per faction), control status (Secure/Contested/Highly Contested)
- [ ] **Declaration pressure visualization** — optional: pulsing border on RS/HRHB-majority municipalities approaching declaration threshold

### 4. PeaceStatusPanel Enhancement (~0.25 session)

The existing PeaceStatusPanel is read-only. Add minimal interactivity:

- [ ] **"Invest" button** per faction card (player faction only) — opens investment map directly from the tactical map side, without going through warroom advance-turn dialog
- [ ] **Staged investments indicator** — if player has staged investments, show count + total cost in the panel
- [ ] **Turn advance button** — "End Turn" button at bottom of panel (peace phase equivalent of the war-phase advance)

### 5. Integration Test (~0.25 session)

- [ ] **Full Sep 1991 → Apr 1992 playthrough** — start peace, invest for 4-6 turns, watch declarations fire, referendum triggers, war transition screen appears, war phase loads correctly
- [ ] **Save/load mid-peace** — save during peace phase, reload, verify state preserved
- [ ] **All 3 factions** — verify each faction can invest (RS gets all 4 types, HRHB gets 3, RBiH gets TO bonus)
- [ ] **Bot factions invest** — verify non-player factions invest via bot AI each turn
