## Situation

Currently one playable scenario exists: **April 1992** (war start, 40w and 52w variants). The endgame design specifies 5 total start dates, all ending at Dayton (21 November 1995).

**What exists:**
- **April 1992:** Full scenario, calibrated to 90%+ area accuracy. Production-ready.
- **January 1993:** Control map PAINTED by user. Initial formations file exists (`initial_formations_jan1993.json`, ~170 brigades). OSID-keyed control at `initial_control/jan1993.json`. Needs scenario manifest + timeline + validation.
- **September 1991:** Peace-phase scenario framework exists (`sep_1991_phase0.json`). Peace pipeline working. Needs war-phase continuation wiring.

**What doesn't exist:**
- **March 1994** (post-Washington) — no control map, no formations, no manifest
- **January 1995** (endgame) — no control map, no formations, no manifest
- **Scenario selection screen** — no UI

**User paints control maps externally** using the existing painter tool (`tools/control_painter/`). This is a blocking dependency — we cannot author scenarios the user hasn't painted.
