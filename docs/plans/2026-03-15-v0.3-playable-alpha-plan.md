## Architectural Decisions (flagged for user review)

1. **Victory check placement**: After all combat+supply steps in war_phases.ts (step ~115). Not at pipeline start (would miss last turn's results).
2. **Save file format**: Same as scenario runner saves (JSON, serialized GameState). No separate save format.
3. **Auto-save location**: `saves/autosave.json` (single file, overwritten each turn). Quick-save: `saves/quicksave.json`. Manual saves: `saves/save_YYYY-MM-DD_HH-MM-SS.json`.
4. **Peace UI scope**: Minimal viable — status panel + investment modal + turn advance. No org-pen heat map in v0.3 (deferred to v0.3.1).
5. **Alliance breakdown scope**: Phase B1 (refugee pressure) only. Phases B2-C deferred. Enough for alliance to degrade and war to trigger.
