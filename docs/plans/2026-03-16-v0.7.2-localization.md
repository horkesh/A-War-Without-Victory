## Architectural Decisions (FLAGGED FOR USER REVIEW)

1. **react-i18next** over custom solution. Standard, well-maintained, good TypeScript support. ~20KB dependency.

2. **BCS in Latin script** (not Cyrillic). Latin is readable by all three ethnic groups. Cyrillic would only serve Serbian readers. For a game about a shared war, Latin is the inclusive choice.

3. **Codex/essay translation is AI-assisted**. Using Sonnet to draft translations, then human review. Professional translation of 40K+ words is expensive; AI draft + native review is a pragmatic middle ground.

4. **Two locales at launch: English + BCS.** Other languages (German, Turkish, Arabic) are post-1.0 if demand exists.
