## Launch Day Sequence

1. **Morning:** Final smoke test — install from store, play tutorial, play 10 turns, verify everything works
2. **Set version:** `package.json` → `1.0.0`. Git tag: `v1.0.0`
3. **Push builds:** Upload to Steam / GitHub Releases / distribution platform
4. **Flip switch:** Make store page public / mark as released
5. **Announce:**
   - Discord: @everyone "A War Without Victory is now available."
   - Twitter: launch post with trailer
   - Press: email reviewers "The game is live"
   - Reddit: post in r/wargames, r/paradoxplaza, r/gamedev
6. **Monitor:** Watch for crash reports, broken saves, critical issues
7. **Hotfix window:** 48-hour availability for emergency patches (v1.0.1 if needed)
