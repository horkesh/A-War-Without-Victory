## Deliverables

### Phase 1: Loading & Transitions (~1 session)
**Assigned to:** UI/UX Developer

- [ ] **Task 1.1:** Loading screen
  - Create: `src/ui/map/components/LoadingScreen.tsx`
  - Faction-themed: dark background with faction crest (subtle), "A War Without Victory" title
  - Progress bar: shows loading stage (data, map tiles, audio, scenario)
  - Tip: random gameplay tip from codex summaries
  - Replaces: blank screen during app initialization

- [ ] **Task 1.2:** Panel transitions
  - Add: CSS transitions to GlassPanel open/close (slide-in from edge, 200ms ease-out)
  - Add: fade transition on panel content swap (150ms crossfade)
  - Add: map mode transition (150ms color interpolation, not instant swap)
  - Keep: snappy feel — never exceed 300ms for any transition

- [ ] **Task 1.3:** Turn advance animation
  - When "End Turn" pressed: brief "processing" overlay with spinning compass rose or clock icon
  - Duration: matches actual turn computation time (typically <100ms after v0.7.0)
  - Minimum: 300ms (so the player registers that something happened)
  - Maximum: no cap (long turns show genuine progress)
  - Transition: fade to command briefing overlay

- [ ] **Task 1.4:** Notification polish
  - Achievement toast: slide-in with gold shimmer effect
  - Event notification: subtle paper-slide animation
  - Briefing items: appear sequentially with 50ms stagger (not all at once)

**Gate:** Game feels polished on all transitions. No jarring instant-swaps.

### Phase 2: Icon & Symbol Polish (~1 session)
**Assigned to:** UI/UX Developer + Graphics Programmer

- [ ] **Task 2.1:** NATO symbology audit
  - Review: all formation icons (formationIcons.ts) against APP-6 standard
  - Verify: size class indicators correct (brigade, regiment, battalion markers)
  - Verify: equipment type symbols correct (infantry, mechanized, motorized, artillery, guards)
  - Fix: any deviations from standard NATO symbology

- [ ] **Task 2.2:** Status indicator consistency
  - Audit: all status badges across panels (health bars, morale, supply, disrupted, entrenched)
  - Standardize: color palette (green=healthy, amber=caution, red=critical, blue=info, gold=special)
  - Standardize: badge shape (rounded rectangles for status, circles for counts, shields for decorations)
  - Fix: any inconsistencies found

- [ ] **Task 2.3:** Map marker polish
  - Review: front line rendering (black-white stripe per napkin)
  - Review: battle markers, operation arrows, sector boundaries
  - Verify: all map elements consistent at different zoom levels
  - Add: subtle shadow/glow to formation icons for readability against all map backgrounds
  - **Front line terrain tinting:** Enrich `buildCorpsFrontLinesGeoJSON` with `terrain_friction_index` per OSID from `settlements_terrain_scalars.json`. MapLibre `line-color` interpolation: high-elevation edges white/blue, lowland edges darker. Design spec: `terrain-map-ux-strategic-design.md` §3.3.

- [ ] **Task 2.4:** Warroom art finalization
  - Verify: faction HQ screens use archival photography aesthetic (not AI art, per napkin)
  - Verify: year-appropriate HQ images for all 3 factions × 5 years
  - Verify: clickable regions work with final art (region bounds match visual elements)
  - If placeholder art exists: flag for user asset delivery (external workstream)

- [ ] **Task 2.5:** Elevation profile on ops axes
  - Add `elevation_at_centroid` to terrain scalars (pre-computed from DEM)
  - Sample elevation along operation axis bezier using OSID centroids
  - Render SVG area chart (~60px tall) showing altitude profile in ops detail panel
  - Hover tooltips already show per-OSID elevation — this adds the visual profile
  - Design spec: `terrain-map-ux-strategic-design.md` §3.1

**Gate:** Consistent visual language across all UI elements. NATO standard compliant. Front lines reflect terrain. Ops axes show elevation.
