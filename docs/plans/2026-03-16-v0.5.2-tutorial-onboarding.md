## Context

This is a complex wargame simulating a real war. Without onboarding, players will be overwhelmed by the faction dynamics, command hierarchy, OSID-based map, operations planning, and diplomatic systems. The tutorial must teach without patronizing — the target audience is strategy gamers who understand wargame concepts but need to learn THIS game's specific mechanics.

**Design principles:**
- Learn by doing, not reading walls of text
- Tutorial is a real (shortened) game, not a separate mode
- Tooltips are always available, not just in tutorial
- The Codex is reference material, not required reading

### Phase 1: Tutorial Scenario (~1.5 sessions)
**Assigned to:** Scenario Creator + Gameplay Programmer

- [ ] **Task 1.1:** Create tutorial scenario definition
  - Create: `data/scenarios/tutorial_apr1992_10w.json`
  - Based on: April 1992 start, but truncated to 10 weeks
  - Player faction: RBiH (hardcoded — most relatable as underdog defender)
  - Simplified OOB: reduce to ~20 key brigades (not full 127 ARBiH)
  - Simplified map focus: Sarajevo + Central Bosnia corridor only (other regions auto-resolved)
  - Victory condition: survive 10 weeks with Sarajevo held

- [ ] **Task 1.2:** Create tutorial objective system
  - Create: `src/sim/tutorial/tutorial_objectives.ts`
  - Types: `TutorialObjective { id, title, description, check: (state) => boolean, completed: boolean, turn_hint: number }`
  - 10 objectives (one per turn, roughly):
    1. "Review your forces" — open OOB sidebar (turn 1)
    2. "Check the front line" — switch to Political map mode (turn 1)
    3. "Read your briefing" — dismiss command briefing (turn 2)
    4. "Set corps stance" — change 1st Corps to defensive (turn 2)
    5. "Fortify Sarajevo" — set Sarajevo sector stance to Fortify (turn 3)
    6. "Check supply" — open Supply map mode (turn 4)
    7. "Launch an operation" — plan and launch one operation (turn 5-6)
    8. "Respond to events" — handle ANY decision event with `requires_player_response: true` (turn 7). **Cross-series finding J:** flexible against event set changes — not hardcoded to specific event_id.
    9. "Review diplomatic pressure" — open war summary diplomatic tab (turn 8)
    10. "Consult your commander" — open AI Advisor panel (turn 9). Auto-completes with note if no API key. **Cross-plan finding #5: teaches the advisor feature early.**
    11. "Survive" — reach turn 10 with Sarajevo held (turn 10)
  - Objectives unlock sequentially (next appears when current completed)

- [ ] **Task 1.3:** Create tutorial state tracker
  - Create: `src/sim/tutorial/tutorial_state.ts`
  - Tracks: which objectives completed, current hint, player actions taken
  - Persists in GameState: `state.meta.tutorial_state?: TutorialState`
  - Deterministic: no randomness in objective checking

- [ ] **Task 1.4:** Register tutorial scenario in registry
  - Modify: `src/scenario/scenario_registry.ts`
  - Add: `tutorial_apr1992_10w` entry with `is_tutorial: true` flag
  - ScenarioSelectionScreen: show tutorial prominently with "Recommended for new players" badge

**Gate:** Tutorial scenario loads, 10 objectives defined, state tracking works.

## Architectural Decisions (FLAGGED FOR USER REVIEW)

1. **Tutorial is a real scenario** (shortened), not a sandbox mode. This means all game systems run normally — tutorial just adds an overlay. Less code, more authentic experience.

2. **Help content is static** (hardcoded in `help_content.ts`), not dynamic. Dynamic help (reading from game state to explain why something happened) is deferred to v0.5.4 contextual advisor.

3. **Codex content generated at dev time**, not runtime. ~60 entries × 200 words = ~12K words. Can be authored by hand or generated with Claude and edited. Shipped with the game binary.

4. **Codex all-unlocked by default** (Option A). Unlock gating adds complexity for marginal engagement benefit in a niche strategy game.
