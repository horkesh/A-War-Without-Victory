# v0.8.0 — External Playtesting — Implementation Plan

**Date:** 2026-03-16
**Status:** PLAN — ready for execution
**Overseer:** Orchestrator + Product Manager
**Prerequisites:** v0.7.3 (Visual Polish) complete. Game is polished, accessible, localized. Feature-frozen.

---

## Context

This is the first time external players touch the game. Everything before this was internal. The goal is NOT to find bugs (though we will) — it's to find **confusion, frustration, and boredom.** Technical bugs matter less than "I don't understand what this button does" or "I don't know why I'm losing."

**This milestone is inherently interactive and CANNOT be night-shifted.**

---

## Deliverables

### Phase 1: Playtest Preparation (~1 session)
**Assigned to:** Product Manager + QA Engineer

- [ ] **Task 1.1:** Create playtest build
  - Tag: `v0.8.0-alpha` build from latest `main`
  - Package: Windows installer (Electron-builder)
  - Include: all scenarios, tutorial, AI features (Cadet mode default)
  - Disable: debug mode, dev tools, console logging in production build
  - Create: install instructions document

- [ ] **Task 1.2:** Design feedback questionnaire
  - Create: `docs/playtesting/playtest_questionnaire.md`
  - Sections:
    1. **First impression** (0-10): How did the first 5 minutes feel?
    2. **Tutorial** (0-10): Did the tutorial prepare you for the game? What was confusing?
    3. **Core gameplay** (0-10): Was the turn-by-turn flow clear? Did you understand your options?
    4. **Difficulty** (1-5 per faction): How hard was each faction?
    5. **Pacing**: Were there boring stretches? Where?
    6. **UI/UX**: Which panels were confusing? Which information was hard to find?
    7. **Historical authenticity**: Did the war feel real? What felt gamey?
    8. **Bugs**: List any crashes, visual glitches, broken features
    9. **Favorite moment**: What was the highlight of your playthrough?
    10. **Would you play again?** Why or why not?
  - Format: structured form (Google Forms or similar) + optional freeform notes

- [ ] **Task 1.3:** Recruit 10-20 testers
  - Target profile: strategy game enthusiasts, wargame players, Paradox/AGEOD fans
  - Sources: Reddit r/wargames, r/paradoxplaza; Discord strategy gaming servers; personal network
  - Each tester commits to: play tutorial + 1 full campaign (~4-6 hours) + fill questionnaire
  - Provide: no guidance beyond tutorial — we're testing discoverability
  - Timeline: 2-week playtest window

- [ ] **Task 1.4:** Telemetry (optional — ARCHITECT DECIDES)
  - Option A: No telemetry (simpler, privacy-friendly)
  - Option B: Opt-in anonymous telemetry: crashes, turn count at quit, which faction chosen, which panels opened, which features never used
  - **Pre-decision: Option A.** Manual questionnaire + save files are sufficient for 10-20 testers.

**Gate:** Playtest build packaged. Questionnaire ready. 10+ testers recruited.

**Gate:** All testers have completed at least 1 full campaign and submitted questionnaire.

### Phase 3: Feedback Analysis (~1 session)
**Assigned to:** Product Manager + Game Designer + QA Engineer

- [ ] **Task 3.1:** Aggregate questionnaire results
  - Create: `docs/playtesting/playtest_results.md`
  - Score averages per question
  - Common themes in freeform feedback
  - Ranked list of confusion points (most testers confused → highest priority)
  - Ranked list of bugs (most testers encountered → highest priority)

- [ ] **Task 3.2:** Categorize findings
  - **P0 — Must fix before release:** Crashes, save-breakers, game-blocking confusion
  - **P1 — Should fix:** Major UX confusion, pacing problems, misleading UI
  - **P2 — Nice to fix:** Minor visual issues, feature requests, balance suggestions
  - **P3 — Post-1.0:** Feature requests that expand scope

- [ ] **Task 3.3:** Create fix plan
  - P0 items: immediate fix in v0.8.0
  - P1 items: fix in v0.8.1 (Final Balance)
  - P2 items: fix in v0.8.1 if time allows
  - P3 items: add to post-1.0 backlog

**Gate:** All feedback categorized. Fix plan documented.

> /simplify → commit "playtesting: feedback analysis + fix plan"
