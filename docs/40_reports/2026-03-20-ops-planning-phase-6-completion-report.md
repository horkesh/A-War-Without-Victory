# Ops Planning Phase 6: G2 UI Integration & P1 Stabilization

**Date:** 2026-03-20
**Task:** G2 Live Briefing Integration + P1 UI Audit Fixes (M1, T1)
**Status:** COMPLETE

## Executive Summary
This phase successfully integrated the G2 Live Briefing (Phase 3 of the Operations Planning modal) with the simulation engine via IPC. Simultaneously, we addressed critical P1-severity UI/UX blockers (M1 and T1) from the March 19th audit, ensuring a stable foundation for the upcoming visual overhaul.

## Technical Implementation

### 1. G2 Live Briefing (Phase 3)
- **Live Data Flow:** Implemented the `usePrediction.ts` hook to query `queryOperationPrediction` via IPC. The hook debounces plan changes (500ms) to prevent simulation thrashing during planning.
- **Narrative Assessment:** The `NarrativeTab.tsx` now renders dynamic commander assessments (typewriter font) generated by the backend.
- **Quantitative Intel:** `RawIntelTab.tsx` displays force ratios, casualty estimates, and per-axis outcomes.

### 2. P1 UI/UX Stabilization
- **Minimap Visibility (M1):** Resolved the "black screen" re-render issue. Minimap now uses `visibility: hidden` and `opacity: 0` to preserve the MapLibre context, with a smooth CSS transition and `requestAnimationFrame` for `resize()` calls.
- **Toolbar Tactical Routing (T1):** Added a dedicated `Command` section to the `TopToolbar.tsx`.
    - `ARMY` / `CORPS`: Direct selection and panning to HQs.
    - `ORBAT`: Direct access to the Order of Battle sidebar.
    - Corrected routing for `IVP` and `Convoys` to their respective tabs in the `WarSummaryModal`.

### 3. Visual Overhaul Strategy
Amended the [UI Visual Overhaul — Design Plan](file:///f:/A-War-Without-Victory/docs/plans/2026-03-19-ui-visual-overhaul-design.md) to adopt a **MapLibre + Deck.gl Hybrid** approach. Deck.gl will handle tactical overlays and animations for superior performance and visual fidelity.

## Verification Results
- [x] **M1:** Minimap preserves layers on toggle; no re-render lag.
- [x] **T1:** Command buttons correctly select player HQs and pan the map.
- [x] **G2:** Live briefings populate correctly based on current plan state.
