## 3. Alliance investigation — why 0.55 not 0.80 after Wave 3F

Sources: `final_save.json` (`.political.war_alliance_rbih_hrhb`, `.military.alliance_locks`,

### Per-turn trace (key turns)

### Root cause (one sentence)

**The `ic_rbih_restraint_post_washington` event fires at turn 106 with a NEW
`ceiling=0.55` lock (expires t=106 — same turn) that pins `war_alliance` to 0.55 before the
0.80 floor can take effect; once the ceiling expires the alliance value has no upward driver
and the floor lock's mode=`floor` semantics evidently apply only on the next clamp/update,
not retroactively raise an already-low value back to 0.80.**

Detail by phase:

1. **t85 — Washington Agreement fires** (`event_fire_counts.washington_agreement_1994=1`,
   `event_last_fired_turn.washington_agreement_1994` = 102 metadata; the *effect* is applied
   at t85 per `replay_sequence` snapshot). Lock installed:
   `[{mode:"floor", value:0.8, expires_turn:10084}]`. war_alliance jumps from −1.0 → 0.80.
   Wave 3F's WA-ceiling eviction is doing its job here — no pre-WA ceiling survives.
2. **t100–t102 — Post-WA restraint** (`ic_rbih_restraint_post_washington` fires).
   `event_last_fired_turn.ic_rbih_restraint_post_washington=106`. This event installs
   a fresh `ceiling=0.55 expires_turn=106` lock. **This ceiling was added POST-WA**, so the
   Wave 3F eviction logic — which evicts ceilings that pre-date the WA — does not touch it.
3. **t100–t106 — wa clamps to 0.55** because effective alliance = `min(ceiling=0.55, …)`;
   the floor=0.8 cannot raise it because floor semantics are presumably "no lower than X"
   but the present-time value (after the ceiling clamp) is already below the floor and the
   engine evidently does NOT lift it back to the floor on each tick.
4. **t106+ — ceiling expires**, leaving just `floor 0.8 exp=10084` plus two short-lived
   internal floors at 0.15. wa stays at **0.55 for the remaining 82 turns** through t188.
   The floor lock is mathematically inert because the current value (0.55) is below 0.8
   but no driver re-evaluates against the floor each turn.

### Detection signal for next wave

`ic_rbih_restraint_post_washington` is the new ceiling installer. Either Wave 3F's
WA-eviction predicate needs to also evict POST-WA `ic_rbih_restraint` ceilings, OR the
floor-application logic must re-clamp `war_alliance` upward to floor each turn (not just at
write-time). Note the floor's `expires_turn=10084` looks like a sentinel (8000-turn lock —
permanent). Recommend hand-off to game-designer for canonical semantics decision.
