## Outcome

Standalone CJS tool at `tools/release/generate_release_notes.cjs` reads `git log <from>..<to>` and emits a Markdown release-body to stdout.

- Default `--from-tag` = most recent `v*` tag via `git describe --tags --match 'v*' --abbrev=0` (currently `v0.6.1` — repo has 16 v* tags).
- Fallback when no v* tag exists: `HEAD~50`.
- Default `--to-tag` = `HEAD`.
- Skips merge commits and `docs(propagation):` aggregation noise.
- Groups by conventional-commit prefix into Features / Fixes / Performance / Other.
- Output is deterministic (git-log order; byte-comparison tie-break only).

`npx vitest run tests/release_notes_generator.test.ts` → **4/4 GREEN** (313 ms).
`npx tsc --noEmit -p tsconfig.json` clean (CJS file is not typechecked; the test file is).

## Determinism contract (CRITICAL — release tooling never gets a free pass on this)

Generator source is forbidden from using:

- `Math.random()`
- `Date.now()` / `new Date(`
- `performance.now()`
- `process.hrtime`
- `localeCompare` (locale-sensitive; banned across the board)

Verified two ways:

1. Static-grep test (T3) — strips comments, then asserts source contains none of the banned tokens. PASS.
2. T4 — asserts source contains the explicit `byteCompare(a, b)` helper and uses it in tie-breaks. PASS.

Commit ordering = git-log order (deterministic by repo state). Tie-break for identical-subject commits is `byteCompare(sha, sha)` — never `localeCompare`.

## Tests (4)

- **T1** — extraction since stable window: runs generator with `--from-tag HEAD~5`, asserts non-empty string output, asserts presence of all section headers (`# AWWV HEAD`, `Built from HEAD~5..HEAD.`, `## Highlights`, `## Features`, `## Fixes`, `## Performance`, `## Other`) and the auto-generated trailer.
- **T2** — idempotent / deterministic: two consecutive runs against the same range produce byte-identical output (string equality + length equality).
- **T3** — static-grep guard: source contains no banned non-determinism tokens (`Math.random`, `Date.now`, `new Date`, `performance.now`, `process.hrtime`).
- **T4** — sort-style guard: source contains no `localeCompare`; explicit `function byteCompare` exists and uses byte-comparison branches.
