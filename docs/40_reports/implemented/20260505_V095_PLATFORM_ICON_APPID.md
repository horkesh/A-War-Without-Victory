## 2. Implementation notes

### 2.1 Icon authoring

Icon was generated by a one-shot deterministic Node script using `pngjs`
(already a project dependency). The script:

- Built a 512x512 RGBA PNG with a subtle vertical gradient background
  (#22:22:36 → #14:14:24).
- Drew two piecewise-linear mountain ridge silhouettes (back ridge dark
  bronze, front ridge muted bronze) using deterministic peak coordinates.
- Drew a small faded 5-point star (off-center upper-left, 62% alpha blend)
  via even-odd polygon rasterization.
- Drew a centered low "AWWV" wordmark using a 5x7 pixel font at scale=5.
- Wrote PNG via `PNG.sync.write` with `deflateLevel: 9, deflateStrategy: 3`
  (Z_RLE) so two consecutive runs produce byte-identical output.
- Built a multi-resolution ICO containing PNG-encoded entries at
  16/32/48/64/128/256 — standard Vista+ ICO format consumed by all current
  Windows shell + electron-builder pipelines.
- Self-checked determinism by rebuilding both files in-process and asserting
  byte-equality before writing to disk.

The generator (`tools/build/__icon_gen_temp.cjs`) was not committed; it ran
once, produced the artefacts, and was deleted. Re-running it must produce
byte-identical icons (verified) so a future re-author can reproduce the
artefacts on demand.

### 2.2 BrowserWindow wiring

A single helper `getAppIconPath()` was added next to the existing
`getBaseDir()` helper, returning `<baseDir>/build/icon.png`. Both
`BrowserWindow` constructors (`createMainWindow` at line 633,
`createTacticalMapWindow` at line 709) now reference it. Singular
ownership: one path resolution helper, two consumers.

### 2.3 AppUserModelId

`app.setAppUserModelId('com.awwv.desktop')` is called pre-`app.whenReady()`
gated by `process.platform === 'win32'` (Electron API is Windows-only;
calling on Linux/Mac is a no-op but the gate documents intent). The string
matches `build.appId` in `package.json` so taskbar grouping, jump lists, and
toast notification identity stay consistent with the installer manifest.

### 2.4 electron-builder discovery

The top-level `build.icon` field at `build/icon.png` is the canonical
electron-builder discovery point for cross-platform icon generation. With
`build/icon.ico` also present, electron-builder embeds it directly in the
Windows .exe rather than re-deriving from PNG (preserving the hand-tuned
multi-resolution ICO).
