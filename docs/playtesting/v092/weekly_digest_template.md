# v0.9.2 Weekly Playtest Digest Template

Publish one anonymized digest per week during an active playtest window.

```text
Week [N] AWWV playtest digest
Date range: [YYYY-MM-DD] to [YYYY-MM-DD]
Builds tested: [versions]
Runs received: [count]
Unique testers: [count]
Scenarios: [40w count] / [188w count] / [probe count]

Top bugs
1. [bug] - [status / owner]
2. [bug] - [status / owner]
3. [bug] - [status / owner]

Top confusion points
1. [confusion] - [planned response]
2. [confusion] - [planned response]
3. [confusion] - [planned response]

Calibration/history flags
1. [place/event/claim] - [canon/calibration status]
2. [place/event/claim] - [canon/calibration status]
3. [place/event/claim] - [canon/calibration status]

Sensitive-history review
- [summary of concerns, if any]
- [how they are being reviewed]

Praise signals to preserve
- [what worked]
- [why it matters]

Already fixed
- [commit / release note]
- [commit / release note]

Next build focus
- [focus 1]
- [focus 2]
- [focus 3]

Thanks
[Short thanks to testers; invite continued feedback.]
```

## Publishing Rules

- Anonymize testers unless they explicitly consent to attribution.
- Do not quote sensitive-history criticism defensively.
- Separate "fixed" from "under review"; do not blur the status.
- Include at least one positive signal so the digest is not only a defect list.
- Link issue IDs, commits, or release notes where possible.
