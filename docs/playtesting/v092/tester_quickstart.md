## First Run

Start with the 40-week scenario unless you already know you want the full 188-week campaign. The 40-week run is enough to test onboarding, commander behavior, early-war pacing, save/load, replay, and endgame reporting.

1. Install or unpack the build.
2. Launch A War Without Victory.
3. Start the default April 1992 campaign.
4. Play naturally for one 40-week run.
5. Save once during the run and reload it.
6. Advance to the end of the scenario.
7. Open the final report and replay screen if available.
8. Submit the feedback form while the session is still fresh.

## What To Watch

- What confused you in the first 10 minutes?
- Which screen told you what to do next?
- Which commander decision felt smart, strange, or opaque?
- Which territorial outcome felt historically wrong?
- Which event or report made the war feel more legible?
- Which text, label, or interaction felt insensitive, evasive, or too abstract?

## What To Send Back

Use the feedback form for overall impressions and AAR notes.

Use the bug tracker for:

- Crash, freeze, or save/load failure
- Broken install or launch
- Visual layout bug that blocks play
- Reproducible wrong click, button, or modal behavior

When filing a bug, include:

- Build version
- Scenario played
- Turn/week if known
- Screenshot if visual
- Save file or log if the issue reproduces
- What you expected to happen
- What actually happened

## Good Feedback Examples

- "I did not understand why 2nd Corps stopped attacking after week 18."
- "The Srebrenica-related text felt too bloodless because it described the outcome only as a strategic penalty."
- "The replay helped me understand the map, but I wanted the summary row to say which faction caused the change."
- "I saved on week 12, reloaded, and the next turn produced the same final hash."

## Not Required

You do not need to play optimally. You do not need prior Bosnian War expertise. You do not need to finish a full 188-week campaign unless you want to.
