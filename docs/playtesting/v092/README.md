# v0.9.2 Playtesting Pack

This folder is the deployable operator package for the v0.9.2 external playtesting lane. It turns the closeout report into assets that can be linked, pasted, or copied into the actual recruitment and feedback workflow.

## Files

- `recruitment_messages.md` - short-form posts, direct-email outreach, and social pitch copy.
- `feedback_form_schema.md` - recommended Google Forms / Tally questions and response routing.
- `playtest_runbook.md` - setup checklist, launch cadence, tester workflow, and triage loop.

## Recommended Launch Order

1. Create the feedback form from `feedback_form_schema.md`.
2. Prepare a stable build link and a first-run support thread.
3. Open a Discord or equivalent support channel with the pinned start-here text from `playtest_runbook.md`.
4. Post the strategy-gamer short-form recruitment first.
5. Send historian/direct-email outreach after the first build feedback pass.
6. Publish weekly anonymized digest notes while the window is open.

## Current Closure Status

The agent-deliverable part of v0.9.2 playtesting is now complete: recruitment copy, form structure, and operator runbook exist as standalone assets. Actual outreach, Discord setup, and feedback collection remain operator-driven.
